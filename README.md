# 🍰 Sweet Hours – Tkinter Food Ordering Application

Sweet Hours is a desktop-based food ordering application developed using Python and Tkinter. The application provides a simple graphical user interface (GUI) that allows users to browse food items, select products, calculate total bills, and generate order summaries.

This project demonstrates core Python programming concepts, GUI development, and basic billing logic implementation.

---

## 🚀 Features

- 🖥️ Desktop GUI built using Tkinter
- 🍕 Multiple Food Categories (Snacks, Beverages, Desserts, etc.)
- 🛒 Add Items and Calculate Total Bill
- 🧾 Automatic Bill Generation
- 🔢 Quantity-Based Pricing System
- 🧮 Real-Time Price Calculation
- 🧹 Reset / Clear Order Option

---

## 🛠️ Tech Stack

- Python
- Tkinter (Python GUI Library)
- Basic Python Logic & Functions
